# 工作标签：只在任务期间存在

主流程：**聊天 → 授权 → 创建工作标签 → 执行操作 → 清理标签和分组 → 回复结果。**

两个例外：

- **需要你登录**：暂停并保留页面，等你继续；等待超过 10 分钟或主动停止则收尾。
- **你要求保留结果**：留下普通页面，移除 Agent 分组和控制。

结束后不需要保留“已停止”任务组，完成记录留在聊天里。你原有的页面不关闭。

## 谁负责什么

- Agent 决定下一步；agent-browser CLI 提供浏览器操作。
- Channel 负责通信和授权；插件负责操作、管理和清理工作标签。
- 聊天走 C4／SQLite；点击、截图等工具结果直接回到 Agent。
