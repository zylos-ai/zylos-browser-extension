# 聊天优先界面（0.9.1）

日常界面只保留聊天记录、消息输入框和轻量连接状态。设置里保留配对与断开入口，连接地址默认折叠；没有新增自动授权或恢复权限。

## 操作流程

1. 首次输入配对码，之后自动连接；连接不代表浏览器授权。
2. 用户直接发消息，普通聊天不创建工作标签。
3. Agent 的工具需要控制权限时，对话里出现授权卡片。
4. 用户点击“允许并继续”，才新建独立工作标签并通过现有 Channel/C4 续跑。
5. 控制期间可查看工作标签或停止。正常完成解除调试并保留已有授权；停止、断线或重载后不自动恢复控制，下次工具按需请求授权。

已删除 ControlCard 及手动授权 UI、设备编号、调试连接细节、大段常驻说明。底层旧 grant 消息只保留兼容用途，当前界面不再发送；没有改变浏览器权限或 Channel 执行协议。
